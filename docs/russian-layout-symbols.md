# Спецсимволы в русской раскладке на Mriya

Шпаргалка: где лежит каждый спецсимвол относительно **русских** букв, на каком слое
и с каким модификатором. Печатная карточка 56 мм — [mriya-symbols-card-56mm.pdf](mriya-symbols-card-56mm.pdf).

## Главный принцип

Клавиатура отправляет скан-код, а конкретный символ выбирает ОС по активной раскладке.
Подписи в комментариях к `layer_2` в [`config/mriya.keymap`](../config/mriya.keymap)
нарисованы для **английской** раскладки. Когда в системе русская — те же клавиши печатают
русские символы.

## Обозначения

- Клавиши названы по **русской букве**, которая сидит на них на базовом слое.
- `L1` — средний большой палец левой руки, `L2` — средний большой палец правой.
- `Shift` — удержание **А** (левый) или **О** (правый) на домашнем ряду.
- «клавиша точки» — клавиша сразу справа от **Ю** (на базовом слое печатает `.`).

## Цифры — L1, правый блок

| | | |
|---|---|---|
| 7 8 9 | → | **Г Ш Щ** |
| 4 5 6 | → | **О Л Д** |
| 1 2 3 | → | **Ь Б Ю** |
| 0 | → | **Ж** |

## L2 в русской раскладке: что реально печатается

**Верхний ряд**

| Й | Ц | У | К | Е | Н | Г | Ш | Щ | З | Х |
|---|---|---|---|---|---|---|---|---|---|---|
| `!` | `"` | `№` | `;` | `%` | `:` | `?` | `*` | `х` | `ъ` | `_` |

**Средний ряд** (Ф Ы В А на L2 — это Alt / Ctrl / Cmd / Shift, не символы)

| П | Р | О | Л | Д | Ж | Э |
|---|---|---|---|---|---|---|
| `/` | `ё` | `Х` | `Ъ` | `(` | `)` | `Э` |

**Нижний ряд**

| Я | Ч | С | М | И | Т | Ь | Б | Ю | клавиша точки | Ъ |
|---|---|---|---|---|---|---|---|---|---|---|
| `\` | `Б` | `Ю` | `Ё` | эмодзи | скриншот | `-` | `=` | `.` | `,` | `+` |

## Нужен символ — куда жать (русская раскладка)

| Символ | Как набрать | Альтернатива |
|---|---|---|
| `=` | **L2 + Б** | |
| `-` | базовый слой, **левая нижняя** (слева от Я) | **L2 + Ь** |
| `_` | **L2 + Х** | **Shift + левая нижняя** |
| `+` | **L2 + Ъ** | **L1 + Э** |
| `.` | базовый слой, **клавиша точки** | **L2 + Ю** |
| `,` | **Shift + клавиша точки** | **L1 + клавиша точки**, **L2 + клавиша точки** |
| `/` | **L2 + П** | |
| `\` | **L2 + Я** | |
| `!` | **L2 + Й** | **L1 + Х** |
| `?` | **L2 + Г** | **L1 + Ъ** |
| `:` | **L2 + Н** | |
| `;` | **L2 + К** | |
| `"` | **L2 + Ц** | |
| `%` | **L2 + Е** | |
| `*` | **L2 + Ш** | **L1 + Р** (там `KP_ASTERISK`, не зависит от раскладки) |
| `(` `)` | **L2 + Д** / **L2 + Ж** | |
| `№` | **L2 + У** | |
| `ё` | **L2 + Р** | удержание **Е** на базовом слое |
| `Ё` | **L2 + М** | |

**Одинаково в обеих раскладках** (подпись L2 = результат): `!` `%` `*` `_` `(` `)` `\` `-` `=` `+`.
Остальные клавиши L2 в русской печатают не то, что подписано.

## Только в английской раскладке

```
@  #  $  ^  &  ~  `  '  |  [  ]  {  }  <  >
```

Этих символов в русской раскладке нет как таковых — ни один слой это не обойдёт,
нужно переключить язык системы. После переключения **L2 читается буквально**,
как нарисовано в комментарии к слою:

Ц=`@` · У=`#` · К=`$` · Н=`^` · Г=`&` · М=`~` · Р=`` ` `` · П=`|` ·
Щ=`[` · З=`]` · О=`{` · Л=`}` · Ч=`<` · С=`>`

Апостроф `'` — базовый слой, клавиша **Э**.

Набирать их без переключения языка можно только макросами с Unicode-вводом,
одним `&kp` не выйдет.

## Оговорка про macOS

Таблица рассчитана на стандартную русскую раскладку Windows и на **«Русская — ПК»**
в macOS. В маковской «Русская» (без «ПК») часть знаков на цифровом ряду сдвинута.
